# Full Stop Cafe — 设定与场景设计

浏览器 low poly 休闲观察游戏：一家接**战斗委托**的事务所里，三个角色过日常。无胜负条件；玩家旁观、偶尔点角色。

外观参考原画在本地 `ref/`（gitignore，不入库）。**三个主人公模型已定型，不要改 `profiles` 里的外观 spec。**

---

## 事务所

| 项 | 内容 |
|----|------|
| 性质 | 接战斗委托的小型事务所（制定计划 → 执行 → 复盘） |
| 老板 | **鸿璐（Honglu）**——事务所对外代表 |
| 组建 | 鸿璐收养了流浪时期的希斯与辛克莱，三人组成事务所 |
| 财力 | 鸿璐非常有钱；办公桌、枪柜、装修可以偏阔气，但整体仍是 low poly 可爱风 |
| 规模 | 单房间约 8×6 m 等轴切开；不做卧室/厨房系统 |

枪会出现，但不血腥：清洁布、枪盒轮廓、任务地图、文件夹。

## 角色设定

> 代码 id 保持英文；中文名用于设定文档与日后 UI。

### 鸿璐 · Honglu · `honglu`

| 项 | 内容 |
|----|------|
| 身份 | 老板 / 事务所代表；收养并组建了现在的「家」 |
| 出身 | 非常有钱 |
| 武器 | **重型手枪 + 短刀**（见 `ref/`） |
| 性格锚点 | 拍板、谈委托、管钱管人；屋里的几何权威位 |
| 主活动位 | **老板办公桌后坐** |
| 次活动位 | 作战大桌（派活）、任务板、访客椅对面谈单 |

### 希斯 · Heath · `heath`

| 项 | 内容 |
|----|------|
| 身份 | 成员；被鸿璐收养前是流浪孤儿 |
| 出身 | **纯孤儿、穷小子** |
| 武器 | **狙击枪**（见 `ref/`） |
| 性格 | **脾气大**；**爱打瞌睡**；**不擅长文书** |
| 能力感 | 战斗可靠，案头工作能躲就躲 |
| 主活动位 | **沙发上躺着/睡着**（最高频闲时状态） |
| 次活动位 | 枪械维护台（整狙）、作战桌站立侧、任务板前、窗边 |

### 辛克莱 · Sinclair · `sinclair`

| 项 | 内容 |
|----|------|
| 身份 | 后辈；被鸿璐收养前亦是流浪/脱轨 |
| 出身 | **富家少爷**，家里出过意外后落入流浪 |
| 武器 | **冲锋枪**（见 `ref/`） |
| 性格 | **努力学习的后辈**；勤快、爱练、爱看档案 |
| 能力感 | **现在其实比希斯厉害一点点**（他不一定张扬；希斯更不服） |
| 主活动位 | **作战/情报桌** 或 **文件柜/任务板前**（学习与准备） |
| 次活动位 | 武器维护台（清冲锋枪）、老板桌侧汇报、访客位陪听谈单 |

### 三人关系（一句话）

鸿璐是把两个无家可归的人捡回来、又开成事务所的家长型老板；希斯像脾气差的哥哥、辛克莱像拼命追赶的弟弟——但战斗上辛克莱略压希斯一头，文书上辛克莱碾压希斯。

## 武器对应（道具以后挂 `joints.handL` / `handR`）

| 角色 | 主武器 | 备注 |
|------|--------|------|
| 鸿璐 | 重型手枪 + 短刀 | 近战 + 火力并重；可腰刀/桌面枪盒 |
| 希斯 | 狙击枪 | 长、需维护台长度；闲时靠沙发更多于抱枪 |
| 辛克莱 | 冲锋枪 | 中等尺寸；学习时段也可枪靠椅 |

枪柜里可放 **三把轮廓道具**（low poly，后期；不急蒙皮）。造型以 `ref/` 为准。

## 房间分区（概念）

```
                 [-Z 后墙 · 窗 · x≈-1.6]
   文件柜/枪柜          任务白板           老板桌区（鸿璐）
   武器维护台
                          作战情报大桌
                    （辛克莱主锚 / 围桌）
   沙发 + 茶几（希斯主锚）
                         地毯休闲
   门 ← (-X, z≈+1.9)
                 [+Z / 玩家侧切开]
```

| 区 | 家具 | 叙事作用 |
|----|------|----------|
| 老板角 | 大办公桌、老板椅、访客椅、台灯、文件/钱匣感 | 鸿璐权威 + 富有 |
| 作战中心 | 大桌、地图/照片叠层 | 委托简报、三人会合 |
| 任务墙 | 白板 / 贴板 | 今日委托；辛克莱常站看 |
| 武备角 | 维护台、枪柜 | 出任务前整装；希斯偶清狙 |
| 休闲角 | 长沙发、茶几、地毯 | **希斯躺平圣地** |
| 入口 | 侧门框（已有） | 客户/出门集合感 |
